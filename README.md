Entry for the [make.fun](https://make.fun/c/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9)
competition **"The Meeting That Should Have Been an Email"** — write one
line, at most 200 characters, that makes a meeting-that-should-have-been-an-email
funny. A judge model reads entries in pairs and keeps the funnier line.

## The entry

> The meeting was "per my last email" read aloud, slowly, by six people who hadn't read it.

The joke: the meeting's entire content already existed as an email — "per
my last email" — and the six people in the room had not even read it. The
turn lands on the last words.

## How it works

`main.py` (pure Python standard library, no dependencies, no network) writes
that single line to `/output/entry.txt`:

```sh
python3 main.py
```
